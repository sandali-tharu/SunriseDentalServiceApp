# Sunrise Dental Clinic - Management System

A Java-based console application designed to manage patient appointments, treatment billing, and user authentication for Sunrise Dental Clinic.

---

## 📌 Key Features
- **User Authentication:** Secure login for authorized staff.
- **Appointment Management:** Register patient appointments with assigned dentists.
- **Appointment Details:** Search and view existing appointment records.
- **Billing & Receipts:** Automated calculation for consultation fees and treatment costs.
- **Help Guide & Exit:** Built-in usage guidelines and graceful exit options.

---

## 🏗️ Architecture & Design Patterns
- **Architecture:** 3-Tier Architecture (Controller / Service / DAO)
- **Design Pattern:** Singleton Pattern for Database Connection
- **Database:** MySQL integration via JDBC
